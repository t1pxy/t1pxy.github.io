# StarCat Monitor Dashboard

A modern monitoring dashboard built with Next.js for StarCat HelpDesk.

## Features

- Dashboard
- Device Management
- Device Detail
- Search & Filter
- Alert Center
- Performance Chart
- Auto Refresh

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Recharts
